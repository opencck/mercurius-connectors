# mercurius-connectors

[English](README.md) | **Русский**

Маршруты исходящих соединений как фабрика `SocketConnector` из Amp: напрямую, через HTTP CONNECT-прокси, SOCKS5, VLESS (на `amphp/vless`) и их цепочки. Через маршрут работает любой клиент AMPHP — HTTP, база данных, SSH.

Часть проекта [Меркурий (Mercurius)](https://github.com/opencck/mercurius) — автономного персонального агента. Пакет не зависит от приложения Меркурия и может использоваться отдельно.

**Статус:** запланирован, кода пока нет.

**Стек:** PHP 8.2+, AMPHP v3.
