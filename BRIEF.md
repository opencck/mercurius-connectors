# BRIEF — mercurius-connectors

Маршруты исходящих соединений для AMPHP v3: напрямую, через HTTP CONNECT-прокси, SOCKS5, VLESS и их цепочки. Маршрут
задаётся URI и превращается в `Amp\Socket\SocketConnector`, поэтому через него работает любой клиент AMPHP — HTTP,
база данных, SSH. Пакет — часть Меркурия (`opencck/mercurius`), подключается сабмодулем в `packages/connectors/` и не
зависит от приложения.

## Назначение и границы

В пакете:

- разбор URI маршрута и отказ на неподдерживаемое до любого сетевого обмена;
- коннекторы: прямой, HTTP CONNECT (`amphp/http-tunnel`), SOCKS5 и SOCKS5h (свой клиент), VLESS (`rekryt/amphp-vless`);
- цепочки маршрутов: каждый следующий узел достигается через предыдущий;
- печатное описание маршрута без секретов.

В приложении остаётся:

- откуда берётся маршрут: `VLESS_URI` для моделей, `TELEGRAM_PROXY` для Telegram, `servers.route` для SSH
  (`vless`, `secret:<имя>` из хранилища секретов, `via:<сервер>`);
- туннель через другой SSH-сервер (`TunnelConnector`, `via:<сервер>`) — это SSH, а не сетевой маршрут;
- пул HTTP-клиентов и их время жизни (`src/Infrastructure/Http/HttpClients.php`);
- хранение URI маршрутов как секретов.

## Устройство

| Класс / каталог | Что делает |
|-----------------|------------|
| `RouteFactory` | `fromUri(?string, ?LoggerInterface)` — коннектор для одного маршрута; `fromRoute(Route, $logger, $via)` — до прокси можно идти через другой коннектор; `chain(...$uris)`; `redact()` — только схема, хост и порт |
| `Route` | Разобранный маршрут: `parse(?string)`, `type()`, `host()`, `port()`, `hasCredentials()`, `vlessConfig()`; `__toString()` без секретов; сериализация запрещена |
| `RouteType` | Перечисление: `Direct`, `Http`, `Socks5`, `Socks5h`, `Vless` |
| `Chain` | Неизменяемый построитель цепочки: `of()`, `then()`, `thenRoute()`, `withLogger()`, `hops()`, `connector()`, `__toString()` |
| `Socks5Connector` | Клиент SOCKS5 (RFC 1928 CONNECT, RFC 1929 логин и пароль); `remoteDns` — имя резолвит прокси (`socks5h`) или мы (`socks5`); можно использовать отдельно |
| `RouteException` | Маршрут нельзя построить: неизвестная схема, `https://`-прокси, SOCKS4, REALITY или XTLS Vision, неверные учётные данные |
| `Internal/Destination` | Разбор адресата `tcp://host:port`, `[::1]:443`, `InternetAddress` на хост и порт |
| `Internal/ExactReader` | Чтение точного числа байт при рукопожатии прокси с сохранением лишнего |
| `Internal/PrefixedSocket` | Сокет, который сначала отдаёт байты, прочитанные после ответа прокси (сервер, говорящий первым, как SSH) |

## Решения

- **Маршрут — это `SocketConnector`.** Так маршрут подходит любому клиенту AMPHP без обёрток под каждый протокол.
- **Ошибка разбора — до сети.** `RouteException` бросается при построении: неверный маршрут не превращается в
  непонятный сбой соединения.
- **Ошибки соединения — обычные AMPHP:** `ConnectException` для повтора или запасного маршрута, `CancelledException` при
  отмене вызывающим; своего вида ошибок соединения пакет не вводит.
- **Нет REALITY и XTLS Vision:** `amphp-vless` их не умеет; такие ссылки отклоняются с причиной и никогда молча не
  становятся обычным TLS. Серверы владельца работают без них, поэтому `amphp-vless` подходит.
- **Нет мультиплексирования VLESS:** каждый `connect()` — новый туннель; пул соединений держит HTTP-клиент, поэтому
  клиент на маршрут один и долгоживущий.
- **SOCKS5 ограничен целиком** (DNS, соединение с прокси, рукопожатие) таймаутом `ConnectContext` и `Cancellation`.
- **Коннектор до прокси захватывается при создании:** коннектор можно потом поставить на весь процесс, и он не пойдёт
  через самого себя.
- **Прямой узел внутри цепочки отклоняется:** прямое соединение — не узел, через который можно пройти дальше; цепочка
  без узлов — это и есть прямой коннектор.
- **Секреты:** URI и учётные данные — `#[\SensitiveParameter]`; в исключениях, журналах, `__toString()` и
  `__debugInfo()` нет паролей, id VLESS и полных URI.

## Проверки

- `composer check` — PHPUnit, PHPStan (уровень `max`), Psalm (`errorLevel="1"`); юнит-тестам сеть не нужна.
- `composer test-integration` — группа `integration`: запрос `https://openrouter.ai/api/v1/models` через VLESS из
  `VLESS_URI`; запускается на сервере проекта, не в CI.
- CI (`.github/workflows/ci.yml`): одна задача, PHP 8.2 (другая версия — вручную через `workflow_dispatch`), push и
  pull request в `master`, изменения только в `*.md` не запускают, `cancel-in-progress`, кеш Composer и анализаторов,
  10 минут; без сети и секретов — группа `integration` в CI не входит.
